# CandyTemp

Identify any sugar syrup stage from temperature — thread to caramel — with °C/°F toggle, uses for each stage, and a visual ladder. Free.

**Live:** https://candytemp.fixoraa.tech

## Features

- Instant temperature → stage identification with uses
- °C/°F toggle for American and European recipes
- Visual stage ladder from thread to caramel
